# Clínica VP 
O Clínica Vida Plena é uma aplicação web desenvolvida com o objetivo de modernizar e facilitar o gerenciamento de atendimentos médicos, oferecendo uma plataforma para organização de pacientes, profissionais da saúde, unidades de atendimento e agendamentos.
O projeto busca otimizar os processos administrativos de uma clínica, centralizando informações e proporcionando uma experiência mais organizada e eficiente para o gerenciamento da rotina de atendimento. uma aplicação direta e concreta.

Funcionalidades

Cadastro e gerenciamento de pacientes.
Cadastro e gerenciamento de profissionais da saúde.
Gerenciamento de unidades de atendimento.
Sistema de agendamento de consultas.
Organização das informações em banco de dados.
Interface web para interação com o sistema.

Tecnologias utilizadas

Python – Linguagem principal de desenvolvimento.
Django – Framework utilizado para construção da aplicação web.
SQLite – Banco de dados para armazenamento das informações.
HTML5 / CSS3 – Estruturação e estilização da interface.

Objetivo do projeto
Este projeto foi desenvolvido como uma aplicação prática de desenvolvimento web, aplicando conceitos de programação orientada a objetos, arquitetura MVC (MTV no Django), gerenciamento de banco de dados, operações CRUD e desenvolvimento de sistemas web.
O objetivo é construir uma solução funcional que possa servir como base para sistemas de gestão de clínicas e estabelecimentos de saúde.
